# 概念设计

## 一句话概念

一名替亡者守契的流浪剑士，在永冬封世的神话古国中承接四位守关者留下的面具，以剑、雷与盾闯过四幕战役，最终决定：让世界继续受一纸古誓支配，还是承担解开誓约后的未知代价。

暂定项目名：**《逆岁：四契》**（工作名，待用户确认）。英文项目名 Oath of the Frost-Crown 可暂留为旧项目标识；“霜冠”不再作为西方王权冠冕意象，而重构为民间对“岁序被封、寒季占满天地”的称呼。

## 设计锚点

- **核心幻想：** 玩家不是被选中的神，也不是神名的化身，而是“拾契人”——为死者收殓遗愿、替活人传递誓言的凡人剑客。每位被击败的守关者留下一张承载其誓约与战技的面具。戴上面具意味着借用其力量，也必须面对其留下的选择。
- **目标体验：** 以清晰、可读、可反制的横版动作战斗为主；战役推进带来神话谜团、人物关系翻转和逐步改变操作策略的面具能力。战斗应有压迫感但可学习，剧情应有情感重量但不长时间阻断操作。
- **玩家动机：** 起初为送一名亡者的最后一封“归乡信”穿越雪封之地；途中发现永冬并非自然灾厄，而是四份守护誓约共同维持的秩序。玩家必须查明自己为何能承接面具，并决定要不要打破这套秩序。
- **核心循环：** 进入区域并读取敌人/环境线索 → 以剑、雷、盾处理普通敌人与平台障碍 → 挑战守关者并学习其攻击规律 → 承接面具、改变战斗选择 → 回看此前线索并推进下一幕。具体战斗规则、数值和面具轮换方式留给顶层设计阶段。
- **跑偏风险：** 若故事退化为“把西方角色换成中国神名”，或面具只是伤害/生命加成，文化转型和成长主张都会失效；若面具能力推翻既有剑/雷/盾操作，或Boss要求未教过的特殊解法，则会破坏用户要求保留的战斗基础。
- **非目标：** 不以收录已知神祇名录为卖点；不做神明百科式剧情；不把作品转成开放世界、复杂装备刷宝或强制格挡的硬核类魂；不承诺未核对现有工程前就能直接替换的源码级方案。

## 设计锚点

本项目参考的不是具体剧情或美术复刻，而是：

- 《九日》：借鉴神话与原创世界规则深度结合、动作反馈服务于战斗判断的方向；不照搬其设定、招式或高难度门槛。
- 《神灵陨落》：借鉴能力选择能够改变玩家战斗行为的思路；不引入其 Roguelite 结构或随机祝福循环。
- 《天穗之咲稻姬》：借鉴将文化主题落实到玩家行动的原则；不引入其种田经营系统。

## 风格与世界观

采用**原创中国神话气质的“岁序民俗奇谭”**：借用节气、山川、祭仪、傩面、符箓、古道与精怪等可识别的文化语汇，但建立原创地名、神灵谱系、仪式逻辑和人物命运，不直接套用现成神话人物及其经典事迹。世界不是历史朝代复刻，也不是泛化的仙侠天庭。

灾厄名为“停岁”：一场本该过去的严冬不再退场，河流、山路、亡者归途与人间节令逐渐凝固。传说源头是“岁契”——先民与四方守关者订下的护世盟约；盟约曾救过人间，也把代价永久压给了某些人。四名Boss分别是守护这份秩序的关键见证者，面具保存的不是抽象元素，而是其誓约、技艺与未竟心愿。以上为**主提案**，具体神话原型与剧情因果在后续阶段深化。

视觉基调为克制的中国神话像素动作片：寒白、黛青、赭红与少量金色构成主色；以风雪留白衬托符纸、漆木、青铜、织物和火光的质感。整体强调“古老仪式在严寒中仍有人守着”，避免纯西式城堡、皇冠、教堂式符号，也避免堆砌无叙事作用的祥云和龙纹。

## 目标玩家与情境

面向喜爱 2D 横版动作、Boss 学习与线性剧情推进的玩家；单次游玩以可分段完成的战役关卡为组织单位。预期体验是“我读懂了对手、用已有招式拆解压力、赢得一种新打法，并因此更理解这个世界”，而非依赖反复刷数值或长篇文本补设定。

难度、游玩时长、平台与商业发行目标目前没有用户提供的已确认信息，均为**待用户确认**；本阶段不以具体市场数据作为立项依据。

## 核心张力

故事的核心问题不是“谁是邪神”，而是：**一份曾经保护众生、如今以牺牲少数人维持的誓约，是否应该被履行到底？** 四名守关者各自有保护他人的理由，也各自被誓约困住。玩家承接面具，既取得继续前行的力量，也逐渐成为旧誓约的继承者；最终胜利应来自理解并作出选择，而不只是击败更大的敌人。
