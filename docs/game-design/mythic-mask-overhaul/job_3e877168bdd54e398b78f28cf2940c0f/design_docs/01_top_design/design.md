# 顶层设计

## 设计目标

将现有四幕 2D 横版剧情动作战役改造成原创中国神话气质的“岁序民俗奇谭”。核心体验是读懂敌人的招式、以剑压迫、以盾截断、借雷反击，再选择一张主面具和一张辅面具，把同一套基础战斗动作组合成不同解法。剧情通过逐幕揭开的四份岁契，令玩家重新判断“停住灾厄”与“让岁序继续流转”各自的代价。

**设计提案基线：**单人、关卡制、线性四幕；战斗与短平台段为主，剧情节点短而有明确转场。建议先以 60Hz 输入与动画节奏作为调校基准。下文具体数值均为首轮可测试目标，不代表已验证的最终平衡值。

## 核心推动力

拾契人沿四幕追索失序的岁契，逐个挑战守关者，获得其面具并改变战斗选择。玩家每次胜利都获得新的作战组合，同时发现守关者并非单纯作恶：他们以各自方式执行旧誓、延缓停岁灾厄，却也在维持导致灾厄扩大的秩序。

核心推动力由三项回报组成：

| 回报 | 玩家得到什么 | 设计用途 |
|---|---|---|
| 叙事 | 一份岁契的事实、守关者的立场、停岁成因的新证据 | 让战斗结果推进故事，而非只清空血条 |
| 玩法 | 新面具的主动技与可配置的辅契被动 | 让成长改变战斗选择，不靠单纯加血加伤 |
| 情绪 | 从“奉命收契”转向“决定誓约是否值得继续” | 将结局抉择建立在逐幕理解上 |

## 大循环

**每幕循环：**进入新区域并接收目标 → 通过短平台段与普通敌人遭遇建立本幕规则 → 在检查点恢复、换装并获得剧情线索 → 进入守关者战 → 战后取得面具／岁契残响 → 通过胜利剧情确认本幕代价与下一步目标 → 转入下一幕。第四幕以终局战及结局页闭合。

四幕节奏提案（具体对白、角色和反转在剧情层细化）：

| 幕 | 体验任务 | 玩法节奏 | 叙事功能 |
|---|---|---|---|
| 序章 | 教会移动、剑、盾、雷与失败重试 | 低压教学后一次短战斗 | 立下拾契人接受追索任务的初始誓约 |
| 第一幕 | 教会读预警、基础攻防与主面具 | 短遭遇—检查点—首领 | 证明守关者有保护百姓的一面，奖励第一张面具 |
| 第二幕 | 让雷与面具被动产生协同 | 多敌种混编、间隔更短的首领窗口 | 揭示岁契的维护代价并动摇命令来源 |
| 第三幕 | 要求玩家利用盾与面具控制节奏 | 更强的投射物／多阶段首领 | 以回忆关和证词反转玩家对旧誓的理解 |
| 第四幕 | 综合运用剑、雷、盾及主／辅面具 | 复合攻击提示、终局考验，避免新规则堆叠 | 让玩家面对“继续封存还是解除停岁”的价值选择 |

建议完整战役目标时长为 **4–6 小时**，每幕约 **45–75 分钟**，序章约 **10–15 分钟**；这是内容规划假设，需由关卡长度和对白量验证，不可据此直接承诺排期。

## 小循环

**单次交锋（约 5–20 秒）：**观察敌人预警 → 判断可格挡／需闪避或拉开（若现有项目无闪避动作，不新增强制闪避依赖）→ 用剑逼迫或积累契息 → 选择盾的精准格挡或雷／面具主动技 → 在敌人硬直或破绽中追加剑击 → 确认敌人状态并重置站位。

**单次探索段（约 1–3 分钟）：**移动与跳跃穿过平台段 → 清理一组有教学目的的敌人或躲过环境危险 → 获得剧情线索／检查点 → 为下一场战斗整理主契与辅契。

## 最小体验单位

最小可玩单位为 **一次 20–40 秒的教学遭遇**：一种普通敌人、一种清晰可读的预警、一种剑击机会、一种盾反或雷击机会，以及一个能解释结果的命中／格挡反馈。它应能回答“我是否看懂了敌人，是否因自己的选择而赢”，而非依赖长关卡和大量剧情。

垂直切片的最小闭环应包含：一段移动平台、一场普通遭遇、一次检查点／对白、一场守关者战、战后面具解锁及一段使用新面具的后续遭遇。单一 Boss 获胜前没有新面具，故后续遭遇必须可用于验证新能力。

## 核心活动流程

1. 从标题页进入序章／继续战役，读取剧情与当前幕目标。
2. 在 CampaignLevel 内移动、跳跃、攻击；首次遇到的新规则由安全场景先行示范。
3. 在战斗中保持剑／雷／盾三种基础选项可用，以契息限制高频爆发。
4. 到达检查点后保存进度、恢复状态，并配置一张主契与一张辅契。
5. 击败守关者后触发胜利剧情、岁契记忆与面具解锁；剧情文本仍由 JSON 驱动。
6. 失败时返回最近检查点，快速重试；胜利时推进幕状态，第四幕进入结局页。

## 关键决策与张力

| 决策 | 即时收益 | 代价／风险 |
|---|---|---|
| 剑连段还是保留行动自由 | 连段稳定造成伤害并累积契息 | 连段后段恢复较长，错过预警可能受击 |
| 举盾等待还是精准格挡 | 举盾降低失误成本；精准格挡可制造反击窗口并获契息 | 举盾移动慢；错判不可格挡招式会受罚 |
| 花契息放雷还是留给面具主动技 | 雷击有稳定远程打断／补伤功能，面具可制造控制或弱点 | 资源不足时无法连续使用两种爆发 |
| 主契与辅契如何搭配 | 可组合一个主动技能及两个不同来源的被动 | 一次只能带一张主契；不允许四个被动全开造成数值堆叠 |
| Boss 破绽时输出还是先调整站位 | 抓住窗口收益高 | 过度贪刀会错过下一次预警 |

## 节奏结构

常规关卡节奏采用“移动／叙事缓冲—普通遭遇—短平台或环境变化—检查点—精英／Boss—胜利演出”的波形。每幕引入至多一个主要战斗教学主题，后续幕复用并组合既有规则；终局不再凭空添加一套与面具无关的战斗操作。

建议将 Boss 预警留给玩家至少 **0.65 秒** 的基础识别与反应时间；高压连招可缩至 **0.45 秒**，但必须先有更长、更安全的示范版本。普通检查点间距目标约 **2–4 分钟**，Boss 门前设置检查点；死亡重试不重复播放已看过的长剧情。

## 输入、输出与反馈

| 输入类别 | 核心动作 | 主要反馈 |
|---|---|---|
| 移动 | 左右、跳跃 | 加速度、落地尘粒、朝向与落地声 |
| 基础战斗 | 剑击、盾／格挡、雷击 | 剑击命中停顿；盾的普通格挡与精准格挡使用不同音色／闪光；雷击给出清楚的命中范围与资源消耗反馈 |
| 面具 | 主契主动技、主契／辅契配置 | 主动技启动有专属图标、音效和可见效果；辅契触发以短提示确认，不遮挡预警 |
| 战役 | 交互／确认／暂停 | 对话、检查点、战役解锁与结局页明确提示状态变化 |

战斗的强反馈层级建议为：精准格挡／Boss 弱点命中 > 普通剑击确认 > 普通受击。镜头震动、闪光与粒子不得盖过 Boss 的预警、碰撞边界或对白可读性。

## 范围与非目标

**立项范围：**保留现有 Godot 4.7 2D 横版与四幕 CampaignLevel 流程；保留标题页、序章、回忆关、失败重试、胜利剧情、结局页、普通敌人及四个 Boss 的战役职能；保留剑、雷电、护盾基础玩法和现有无头测试／Debug Runner 的验收入口。剧情与美术整体转为原创中国神话气质的岁序民俗奇谭；增加四张 Boss 面具的主动／被动组合。

**非目标：**不引入开放世界、随机地牢、装备掉落、复杂技能树、多人模式、农耕／生存资源管理或需要面具才能通过主线的硬门槛；不将历史神祇姓名与原西方角色简单一对一替换。面具改变决策但不可成为击败 Boss 的唯一解。

## 开放问题

- **待核对工程事实：**现有剑／雷／盾具体输入、伤害和场景切换接口；本设计只规定行为目标，不假设源码实现。
- **待验证数值：**上述时长、帧数、伤害、契息与检查点节奏均为首轮调校基线，应经可玩切片和玩家测试修订。
- **待进一步设计：**四幕具体角色关系、对白、反转、四位守关者身份与每阶段招式；在此顶层先锁定叙事职能与玩法节奏，不把未确认的人物设定当成既有事实。
